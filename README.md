# TCM AI Operational Efficiency Database

Automated research machine tracking companies that show **quantified, AI-attributable
operational-efficiency improvement**. Companies are excluded by default; admission requires
evidence that survives an explicit attempt to refute it.

- `data/ledger.md` — the master state ledger (source of truth)
- `data/state.json` — machine-readable rendering of the ledger
- `build.py` — static site generator
- `docs/` — the published site (GitHub Pages)

Universe: 345 names. Baseline: 21 Jul 2026 (Phase 1 deep verification).
