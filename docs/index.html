How to read the score
Conviction, 0–100, built from quantification quality (0–40), visibility in the reported financials (0–25), credibility of the causal mechanism (0–20) and management track record (0–15), less penalties for promotional tone, AI-revenue conflation and shifting metric definitions. A score only moves when new evidence arrives — the date it last moved is shown, so age is visible rather than silently decaying the number.
